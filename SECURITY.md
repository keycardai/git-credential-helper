# Security Policy

`keycard-git` hands credentials to git, so we take reports seriously.

## Reporting a vulnerability

Email [security@keycard.ai](mailto:security@keycard.ai). Please do not open a
public issue or pull request for a vulnerability.

Include what you found, how to reproduce it, and the version
(`keycard-git version`). We will acknowledge your report, keep you updated
while we work on a fix, and credit you in the release notes if you want.

## Supported versions

Security fixes go into the latest release.
